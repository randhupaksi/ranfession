# Peta dokumentasi Ranfession

Gunakan indeks ini sebelum mengubah pengalaman. Ranfession adalah surat digital statis untuk satu pengirim dan satu penerima; batas privasi dan **Final Click** lebih penting daripada menambah fitur baru.

| Dokumen                                                                     | Gunakan saat                                                                    |
| --------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| [AGENTS.md](../AGENTS.md)                                                   | Membutuhkan aturan operasional, batas produk, aksesibilitas, perintah, atau Git |
| [Gambaran produk](product-overview.md)                                      | Menilai visi, alur hero-ke-scroll, nada, atau cakupan produk                    |
| [Traceability PRD](requirements-traceability.md)                            | Memeriksa kebutuhan PRD, keputusan yang menggantikannya, dan bukti implementasi |
| [Arsitektur](architecture.md)                                               | Mengubah modul, state journey, validasi config, atau struktur aplikasi          |
| [Panduan menulis konten](content-authoring.md)                              | Mengubah `src/content/story.ts`, scene, label, atau visual config               |
| [Interaksi, aksesibilitas, dan motion](interaction-accessibility-motion.md) | Mengubah scroll, Final Click, focus, reduced motion, atau GSAP                  |
| [Audio, privasi, dan publikasi](audio-privacy-deployment.md)                | Mengubah ambience, data publik, `noindex`, static hosting, atau Vercel          |
| [Verifikasi](verification.md)                                               | Menjalankan atau memperbarui lint, unit test, E2E, dan skenario manual          |

Aturan baca cepat untuk agent:

1. Mulai dari `AGENTS.md` dan gambaran produk.
2. Baca dokumen per-batas yang terpengaruh, bukan seluruh dokumentasi tanpa kebutuhan.
3. Jika prose dan source bertentangan, gunakan source untuk perilaku saat ini lalu perbarui dokumen yang tertinggal.
4. Jangan menganggap PRD sebagai izin untuk menambah backend, tracking, chat, respons penerima, atau data pribadi.
